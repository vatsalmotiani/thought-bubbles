# Thought Bubbles Advertising Website

A modern single-page website for Thought Bubbles Advertising agency built with Next.js 15.

## Tech Stack

- Next.js 15
- React 19
- Tailwind CSS
- Framer Motion
- Radix UI

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000)

## Available Scripts

- `npm run dev` - Development server
- `npm run build` - Production build
- `npm start` - Production server

## Project Structure

```
├── app/          # Pages and routes
├── components/   # UI components
├── data/         # Content data
└── lib/          # Utilities
```

## Deployment

Deploy to Vercel:
```bash
vercel deploy
```
