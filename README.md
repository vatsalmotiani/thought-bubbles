# Thought Bubbles Advertising Website

A modern, responsive website built with Next.js 14 for Thought Bubbles Advertising agency.

## 🚀 Features

- **Next.js 14** with App Router
- **React 18** with modern hooks and patterns
- **Tailwind CSS** for styling with custom design system
- **Framer Motion** for smooth animations
- **Radix UI** components for accessible UI elements
- **Responsive design** optimized for all devices
- **SEO optimized** with proper metadata
- **Contact form** with email functionality
- **Gallery and case studies** showcase
- **Smooth scrolling** and modern UX

## 🛠️ Tech Stack

- **Framework**: Next.js 14
- **Language**: JavaScript (JSX)
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI + shadcn/ui
- **Animations**: Framer Motion
- **Forms**: React Hook Form
- **Email**: Nodemailer
- **Icons**: Lucide React
- **Carousel**: Embla Carousel

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd tb-website
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint

## 🎨 Design System

The project uses a custom design system built with Tailwind CSS:

- **Colors**: Custom brand colors (tb-blue, tb-black, tb-bg)
- **Typography**: Inter, Poppins, and other custom fonts
- **Components**: Consistent UI components using shadcn/ui
- **Spacing**: Tailwind's spacing scale
- **Animations**: Framer Motion animations
